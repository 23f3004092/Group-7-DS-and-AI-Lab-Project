
Following our discussions in the review meeting yesterday, here are my feedback comments. Please incorporate them and resubmit the Milestone 2 document by EOD Monday.  
  

-   Consolidate all sub reports into one report with simplification. Push details and charts to Appendices and provide core accomplishments and justifications in the main report. Currently the report is a very difficult read.  
    
-   Redesign the main architectural flow with proper integration of the Yield subsystem as discussed in terms of data and process flow.  
    
-   The Yield subsystem is still in the design phase. However, the presentation claims are not substantiated.  
    
-   The KCC preprocessing pipeline is not yet fully complete. The report explicitly states that Q&A deduplication and MuRIL chunk generation remain to be executed before the corpus becomes training-ready.  
    
-   Report actual post-deduplication statistics instead of estimated values once preprocessing has been completed.  
    
-   Clearly distinguish datasets that are fully prepared from those still undergoing preprocessing.  
    
-   Complete verification of the licensing/source information for the MISS document before the final submission.  
    
-   The rationale for selecting the final datasets is not sufficiently justified. The report does not explain why these represent the best choice over other publicly available alternatives.  
    
-   The report introduces multiple datasets for the same subsystem (especially yield prediction) without clearly stating which dataset will ultimately be used for the deployed system (Pan India and UP).  
    
-   There is no consolidated table summarizing all datasets, their purpose, final size, and intended usage within the project.  
    
-   Dataset descriptions occasionally repeat information already presented in the identification section.  
    
-   The Vision dataset EDA is significantly more comprehensive than the RAG and Yield EDA, leading to an imbalance across project components.  
    
-   EDA observations are not translated into concrete preprocessing decisions.  
    
-   Statistical summaries are presented but higher-level insights are not presented.  
    
-   The report documents what was cleaned but does not consistently quantify the impact of each cleaning operation.  
    
-   Vision dataset integration is well described but equivalent integration methodology for the RAG corpus (PDFs + KCC) is missing.  
    
-   No explanation is provided for how multiple knowledge sources will coexist inside the vector database.  
    
-   While the image label harmonization is well described. text corpus harmonization receives much less attention.  
    
-   There is little discussion of standardizing: crop names, district names, scheme names, agricultural terminology across different document sources.  
    
-   Data Governance focuses primarily on licensing and ethics.  
    
-   Version management of datasets is not discussed.  
    
-   Dataset update strategy is absent.  
    
-   Long-term maintenance of the knowledge base is not described.  
    
-   The preprocessing pipeline is comprehensive but lacks a single end-to-end workflow diagram.  
    
-   Several preprocessing decisions and choices (image size, chunk size, overlap size) are stated but not fully justified or experimentally verified or motivated. Chunking strategy is not yet determined.  
    
-   The report mixes datasets that are fully prepared with datasets still undergoing preprocessing.  
    
-   There is no readiness matrix indicating: completed, partially completed, pending artifacts.  
    
-   Dataset download dates are not recorded.  
    
-   Dataset versions are not recorded.  
    
-   Source document versions are not recorded.  
    
-   No checksum or integrity verification is mentioned.  
    
-   Many preprocessing operations are described qualitatively rather than summarized quantitatively.  
    
-   A single summary table showing - Raw -> Removed -> Retained -> Final for every dataset would improve readability.  
    
-   Some sections repeat information already discussed elsewhere.  
    
-   Reduce repetition and improve document readability through summary tables and workflow diagrams.
